# Discord-Bot-Magister
A discord bot with the name "Magister" and powered using Groq.

What does it do?
It's a discord assistant made for fun. It does a couple of tasks like:
- Getting and summarising the number one news article online.
- Generating a prompt for general discussions or debates.
- Set timers.

Requirements:
You need a groq account, discord account, and API keys from the news source.
